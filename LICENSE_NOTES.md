# Licensing and attribution

No new project-wide licence has been assigned in this packaging step. The project owner can select a licence for their own original code and text. Scientific citations are listed in the implementation notes, EOS provider files and manuscript bibliography.

Third-party material retains its own notices and terms:

- CompOSE EOS tables: original provider README, data sheets and source information remain in each EOS folder. A code licence does not automatically relicense provider datasets.
- `docs/article/aa.cls` and `aa.bst`: original A&A/template notices retained unchanged.
- Python dependencies are installed separately and retain their own licences.

Provider table bytes are not modified by the documented reader masks. Keep these notices and provenance files when redistributing the package.
